# Planassiant Product Docs

Planassiant is a lightweight Learning OS for organizing learning content, learning nodes, resources, notes, and study progress.

## Product Direction

- Desktop first.
- Offline first.
- No cloud sync in the first version.
- No calendar-centric layout.
- Minimal, quiet, readable UI.

## Product Notes

- Keep design references under `product/design/`.
- Keep the application source under `app/`.
