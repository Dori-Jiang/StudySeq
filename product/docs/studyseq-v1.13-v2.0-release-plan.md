# StudySeq / 知序 V1.13 与 V2.0 发布计划

## 文档定位

本文件记录 StudySeq / 知序 V1.13.0 功能冻结和 V2.0 稳定发布计划。

- V1.13.0 是 V2 前最后一个功能冻结版本。
- V2.0 是稳定发布版本，不新增产品能力。
- V2.0 之后只进入 `2.0.x` 稳定修复线。
- 总路线见 [`studyseq-pre-v2-roadmap.md`](studyseq-pre-v2-roadmap.md)。

## V1.13.0 版本目标

V1.13.0 不新增能力，只做四项 V2 前能力的全量稳定化、旧库升级验证、真实 App 回归和发布候选收口。

V1.13.0 必须确认：

- 代码文件载入与高亮稳定。
- 基础手写笔记稳定。
- PDF 页面手写批注稳定。
- 更多视频格式支持稳定。
- V1.8.1 以前核心流程零回归。
- 旧库从 V1.0 / V1.1 / V1.4 / V1.6 / V1.8.1 升级到 V1.13.0 后可正常使用。
- 删除只影响 App 管理副本和派生文件，不影响用户原始来源文件。
- 断网状态下本地资料阅读、笔记、手写和批注可用。

| 阶段 | 目标 | 重点 | 建议 agent |
| --- | --- | --- | --- |

| A6 | RC 收口 | 问题分级、延期清单、tag/branch 准备 | `doc-updater` |

## V2.0 版本目标

V2.0 是稳定发布版本，不新增产品能力。V2.0 只接收 V1.13.0 发现的阻塞修复、文档收口、版本号统一、安装包验证和发布记录。

V2.0 进入条件：

- V1.13.0 release gate 全绿。
- P0/P1 问题为 0。
- P2 问题有明确延期记录，不影响主要学习流程。
- 旧库升级矩阵通过。
- 真实 App 手测矩阵通过。
- debug/release 安装包均可启动，无黑色控制台窗口。
- V2 后版本线明确切到 `2.0.x` 稳定修复，不再塞新功能。

V2.0 不进入：

- 新资料类型。
- 新编辑器能力。
- 新统计、同步、账号、云端能力。
- 代码编辑/运行/调试。
- PDF 导出带批注。
- 视频剪辑、字幕、播放列表。
- 手写 OCR、压感、无限白板。

## V1.9 - V1.12 Release Gate

V1.9.0 / V1.9.1 发布前必须通过：

- 常见代码文件导入：`ts/tsx/js/jsx/py/rs/go/java/cpp/c/h/cs/json/yaml/html/css`。
- UTF-8、GBK、中文注释、长行、大文件、无扩展名、未知扩展名。
- 高亮失败降级为只读等宽纯文本。
- 代码内容不得作为 HTML 直接注入。
- 删除代码资料只删除 App 管理副本，不删除原始来源文件。
- 旧 txt/PDF/图片/Office/视频/笔记流程不回退。

V1.10.0 / V1.10.1 发布前必须通过：

- 创建、编辑、保存、删除手写笔记。
- 笔、橡皮、颜色、粗细、撤销、重做、清空。
- 鼠标、触控板、手写笔基础输入。
- 重启后手写笔记恢复。
- 窗口缩放后笔迹不明显漂移。
- 保存失败不丢当前画布状态。
- 删除学习内容时关联手写笔记处理正确。
- 旧纯文本笔记切换前保存流程不回退。

V1.11.0 / V1.11.1 发布前必须通过：

- PDF 当前页批注创建、保存、显示、隐藏、清除。
- 批注按 `material_id + page_number` 隔离。
- 缩放、翻页、目录跳转后批注不明显漂移。
- 多 PDF 批注互不串用。
- Office 派生 PDF 批注可用。
- 删除 PDF / Office 源资料 / 学习内容时清理对应批注。
- 不改写用户原 PDF 文件。
- V1.8.1 PDF 页码、缩放、目录、Office 派生 PDF 主线不回退。

V1.12.0 / V1.12.1 发布前必须通过：

- MP4/WebM 旧流程不回退。
- 承诺支持格式每种至少 2 个真实样本通过。
- 中文文件名、空格文件名、长文件名。
- 大文件、长视频、拖动进度、暂停、继续播放。
- WebView2 不能直接播放的格式走稳定派生 MP4 缓存。
- 转码失败、缓存损坏、磁盘不足进入明确错误终态。
- `.derived/video-*` 纳入迁移、统计、cleanup、删除链路。
- 不支持格式提示友好，不永久 loading。
- 断网可播放本地可用资料。

## 真实 App 手测矩阵

| 模块 | 必测项 | 通过标准 |
| --- | --- | --- |
| 学习内容 | 创建、编辑、删除、重启恢复 | 字段、状态、进度不丢失 |
| 资料导入 | txt、图片、PDF、Office、代码、视频 | 均进入 App 管理库，可预览或给出稳定错误 |
| PDF | 目录展开、点击跳页、页码恢复、缩放恢复 | 重启后仍恢复到正确页码和缩放 |
| 代码 | 中文路径、中文注释、高亮失败降级 | 不白屏，不注入 HTML |
| 视频 | 播放、暂停、拖动进度、继续播放 | MP4/WebM 和新增格式主线稳定 |
| 不支持视频 | 导入或预览不支持格式 | 明确提示，不永久 loading |
| 文件夹 | 新建、嵌套、移动、重命名、递归删除 | 返回上下文正确，删除影响清晰 |
| 笔记 | 创建、编辑、删除、切换前保存 | 重启后恢复，失败不丢输入 |
| 手写笔记 | 绘制、保存、删除、缩放、重启 | 笔迹不明显漂移 |
| PDF 批注 | 按页批注、翻页、缩放、目录跳转 | 批注绑定正确页码 |
| 删除 | 删除资料、文件夹、学习内容 | 只删 App 管理副本和派生文件，不删原始来源 |
| 断网 | CDP offline 或系统断网 | 本地阅读、笔记、批注可用 |

## 回归主流程

1. 新建学习内容，填写状态、截止日期、预计工时、进度。
2. 新建嵌套文件夹，导入 txt / 图片 / PDF / Office / 代码 / MP4 / WebM / 新增视频格式。
3. 打开 PDF，展开目录，跳页，缩放，返回，再次打开确认恢复。
4. 打开代码文件，确认高亮和复制，未知扩展降级为纯文本。
5. 打开视频，播放、暂停、拖动进度，返回主页后继续学习。
6. 创建纯文本笔记，切换资料前保存，重启后确认恢复。
7. 创建手写笔记，编辑、撤销、重做、保存，重启后确认恢复。
8. 在 PDF 第 1 页和第 2 页分别批注，缩放/翻页/目录跳转后确认不串页。
9. 删除单个资料，确认 App 管理副本和派生文件清理，原始来源文件仍存在。
10. 删除嵌套文件夹，确认递归影响提示和关联清理。
11. 删除学习内容，确认资料、笔记、手写、批注、阅读状态清理。
12. 断网后重复打开本地 txt/PDF/代码/笔记/手写/批注。
13. 关闭 App，重新启动，确认学习内容、资料层级、笔记、PDF 状态、视频位置保留。

## P0 / P1 / P2 处理规则

P0：

- 数据丢失、误删原始来源文件。
- 旧库无法启动或迁移失败。
- App 崩溃、启动失败、安装包不可用。
- 删除链路越界删除。
- 安全问题：路径泄露、任意文件读取、命令注入、HTML 注入。
- 主要资料类型无法打开且无降级。

处理规则：立即停止发版，必须修复并补自动化或手测回归。

P1：

- 核心流程可用但有明显错误终态。
- PDF 页码/缩放/批注错位。
- 视频继续播放错误。
- 手写保存失败、切换丢输入。
- 派生缓存损坏后不能恢复。
- 中文文件名、嵌套文件夹、断网核心场景失败。

处理规则：V1.13/V2.0 发布前必须清零；确认为低触发环境问题也要有复现记录和规避说明。

P2：

- 非核心格式兼容差。
- 个别复杂 Office / 视频样本效果不好。
- 轻微 UI 对齐、提示文案、性能边界问题。
- 不影响数据安全和主流程的体验问题。

处理规则：允许延期，但必须记录到 V2 后 `2.0.x` 稳定修复清单，不得伪装通过。

## 发布 / Tag / Release Gate

建议版本线：

- `v1.9.0`、`v1.9.1`
- `v1.10.0`、`v1.10.1`
- `v1.11.0`、`v1.11.1`
- `v1.12.0`、`v1.12.1`
- `v1.13.0`
- `v2.0.0`
- V2 后只开 `v2.0.1`、`v2.0.2` 等稳定修复 tag。

每版发布前必须记录：

- 版本目标是否完成。
- 不进入范围是否仍被排除。
- 自动化命令结果。
- 真实 App 手测结果。
- 旧库升级结果。
- 已知 P2 延期项。
- 产物路径：`studyseq.exe`、MSI、NSIS。
- 当前 commit hash。
- tag 是否已推送远端。

推荐发布步骤：

```powershell
git status --short --branch
git log -1 --oneline

# release gate 全绿后
git tag vX.Y.Z
git push origin vX.Y.Z
git push
```

V2.0 发布后：

- 主线进入 `2.0.x` 稳定修复。
- 不再把新产品能力合入 V2.0 稳定线。
- 如要探索 V2 后新能力，另起开发分支，不影响 `v2.0.0` 稳定基线。

## 回退策略

自动化 gate 失败：

- 不打 tag。
- 不生成正式发布记录。
- 保留失败命令、错误摘要和复现步骤。
- 优先修第一个有意义错误，再跑最窄验证。

真实 App 手测失败：

- 记录复现步骤、期望、实际、样本文件、数据目录、App 版本。
- P0/P1 必须修复后重跑完整相关矩阵。
- P2 可延期，但必须写入已知问题。

安装包失败：

- 保留上一个稳定版本产物。
- 新版本不得覆盖稳定 tag。
- 修复后重新 build，确认版本号、窗口子系统、启动、数据目录。

数据迁移失败：

- 立即停止发布。
- 用旧库备份复现。
- migration 必须可重复执行，失败不得破坏旧数据。
- 修复后补旧库升级测试样本。

发布后发现 P0：

- 立即撤回 release 说明中的推荐下载。
- 新建 `2.0.1` 或对应 patch 修复。
- 不移动已发布 tag；用新 tag 修复，保留可追溯历史。

发布后发现 P1：

- 进入最近一个 patch 版本。
- 如果影响面大，暂停推广当前包。
- 修复后补真实 App 回归证据。

发布后发现 P2：

- 进入 `2.0.x` 稳定修复池。
- 不为 P2 追加新功能型改动。
