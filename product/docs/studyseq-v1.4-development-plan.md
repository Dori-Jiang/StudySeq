# StudySeq / 知序 V1.4 开发计划

## 文档定位

本文件记录 StudySeq / 知序 V1.4 的开发计划。

- V1.4 主题是“主页最近打开位置”。
- 本版本不是学习统计、日历打卡或学习记录中心。
- 本版本目标已经用户评审确认（2026-06-14）。
- 总进度仍记录在 `product/docs/studyseq-project-progress.md`；本文件用于展开 V1.4 的版本目标、阶段计划、验收标准和风险。

## 版本目标

V1.4 目标：在主页学习内容列表中，为每个学习主题显示最近打开位置，帮助用户从上次阅读或播放的位置继续学习。

主页仍然只做一件事：展示学习内容列表和学习内容进度。最近打开位置只是每个学习主题栏里的辅助信息，不新增独立页面或复杂统计。

## 用户价值

用户打开 StudySeq 后，可以直接在主页看到：

- 上次什么时候打开这个学习主题。
- 上次打开的是哪个资料文件。
- 上次阅读或播放停在什么位置。

这样用户不需要进入详情页后再回忆自己看到哪里，也不需要手动打卡或维护学习记录。

## 范围

### 进入 V1.4

- 主页每个学习主题栏显示最近打开摘要。
- 最近打开摘要只包含三类信息：
  - 上次打开时间。
  - 上次打开文件。
  - 上次打开文件 / 视频到哪里。
- PDF 显示上次打开页码。
- 视频显示上次播放时间点，并在再次打开时恢复播放位置。
- 普通文件显示上次打开文件和上次打开时间；无法定位具体位置时不强行展示虚假位置。
- 删除资料或删除学习内容后，最近打开摘要不引用失效资料。
- 资料库位置设置：允许用户在主页选择资料库存放位置，App 实际使用所选位置下的 `StudySeqData\materials` 专用目录，减少 C 盘占用。

### 不进入 V1.4

- 日历打卡。
- 最近自动足迹列表。
- 右侧自动记录规则。
- 近 14 天足迹或热度图。
- 当前重点模块。
- 学习时长统计。
- 连续学习天数。
- 自动计算学习进度百分比。
- 独立学习记录中心。
- 手写笔记。
- Office 转 PDF。

## 主页展示口径

每个学习主题栏中，最近打开摘要只显示以下字段：

| 字段 | 示例 | 说明 |
| --- | --- | --- |
| 上次打开时间 | 今天 19:35 | 来自资料最近打开记录 |
| 上次打开文件 | 课程视频 03.mp4 | 来自最近打开的资料 |
| 上次打开位置 | `00:24:18` / 第 14 页 | 视频显示时间点，PDF 显示页码，普通文件可为空 |

空状态：

- 学习主题从未打开过资料时，显示“暂无打开记录”。
- 最近打开资料已被删除时，清理对应摘要，显示“暂无打开记录”。
- 普通文件没有可定位位置时，只展示时间和文件名，不展示“打开位置”。

## 开发计划

V1.4 采用 A1-A6 分阶段推进。阶段顺序先稳定数据合同，再接入 PDF / 视频 / 普通文件的最近位置保存，最后改造主页 UI 和回归验证。

| 阶段 | 主题 | 目标 | 主要工作 | 验收标准 | 建议 agent |
| --- | --- | --- | --- | --- | --- |
| A1 | 最近打开数据模型 | 定义主页最近打开摘要的数据来源 | 为资料最近打开状态设计字段或表结构；覆盖 `last_opened_at`、最近位置类型、PDF 页码、视频秒数、普通文件空位置；确定旧库迁移策略 | 旧 SQLite 可升级；无记录时主页稳定显示空状态；删除资料后不留悬空摘要 | `architect`、`database-reviewer` |
| A2 | 后端保存与查询命令 | 让 Rust / Tauri 层负责最近打开状态 | 新增或扩展 command：打开资料时记录时间；PDF 翻页保存页码；视频播放保存秒数；主页列表返回每个学习内容的最近打开摘要 | Rust 测试覆盖保存、查询、旧数据为空、资料删除清理和学习内容删除清理 | `tdd-guide`、`rust-reviewer` |
| A3 | 视频播放进度记忆 | 补齐视频继续播放能力 | 在现有视频预览中保存 `currentTime`；重新打开同一视频时恢复播放时间点；切换资料时隔离状态 | MP4 / WebM 重新打开能回到上次位置；切换视频不串位置；不支持格式不写入播放位置 | `typescript-reviewer`、`e2e-runner` |
| A4 | PDF / 普通文件最近位置统一 | 统一主页展示口径 | 复用已有 PDF 阅读状态输出页码；普通文件只记录上次打开时间和文件名；位置不存在时不展示虚假位置 | PDF 显示“第 N 页”；视频显示 `00:24:18`；普通文件显示文件名和上次打开时间 | `typescript-reviewer` |

| A6 | 回归验证与文档收口 | 确认 V1.4 不破坏 V1.2 / V1.3 主线 | 更新项目文档和验收标准；跑前端、Rust、Tauri 构建；真实 App 手测 PDF、视频、普通文件、删除资料、删除学习内容、旧库升级 | 自动化命令通过；真实 App 下 PDF / 视频 / 普通文件最近位置正确；删除后无失效引用 | `e2e-runner`、`doc-updater` |

## 建议实现顺序

1. **A1 数据模型**
   先确定最近打开摘要的数据来源和迁移方式，避免前端先做 UI 后缺少稳定数据合同。

2. **A2 后端保存与查询命令**
   主页需要的摘要应由 Rust / Tauri 层统一返回，前端不直接拼 SQLite 数据。

3. **A3 视频播放进度记忆**
   视频是 V1.4 相对新增的“继续位置”能力，需要单独验证播放时间点保存和恢复。

4. **A4 PDF / 普通文件统一口径**
   PDF 已有阅读状态基础，重点是统一输出给主页；普通文件只保留真实可得的信息。

5. **A5 主页 UI 改造**
   数据合同稳定后再改主页，确保显示内容准确。

6. **A6 回归验证**
   V1.4 涉及主页、详情页阅读、视频预览、PDF 状态和删除清理，必须覆盖旧库升级和删除路径。

## 数据与技术边界

- SQLite 仍由 Rust repository 层访问。
- 前端只通过 Tauri command 获取主页列表和最近打开摘要。
- 最近打开摘要不能依赖前端本地临时状态作为唯一数据源。
- 删除资料、删除文件夹、删除学习内容时，必须清理或失效化相关最近打开摘要。
- 视频播放位置保存应低频触发，避免高频写库。
- PDF 页码继续复用现有资料阅读状态能力，避免重复状态表造成冲突。
- 资料库位置支持默认 AppData 位置，以及用户在主页选择的存放位置下的 `StudySeqData\materials` 专用目录；不要把用户选择的根目录直接作为清理根，也不要开放全盘 Tauri asset 访问范围。

## 验收标准

### 功能验收

1. 从主页进入学习主题，打开 PDF，翻到第 N 页，返回主页后对应学习主题栏显示该 PDF 和第 N 页。
2. 关闭重开 App 后，主页仍显示该 PDF 和第 N 页。
3. 打开视频播放到指定时间点，返回主页后对应学习主题栏显示该视频和时间点。
4. 再次打开该视频时，能恢复到上次时间点附近。
5. 打开普通文件后，主页显示上次打开时间和文件名，不显示虚假的页码或时间点。
6. 学习主题从未打开过资料时，主页显示“暂无打开记录”。
7. 删除最近打开的资料后，主页不再引用该资料。
8. 删除学习内容后，其最近打开摘要一并清理。
9. 旧版本数据库升级后，已有学习内容、资料、PDF 阅读状态、文件夹和笔记保持可用。
10. 断网状态下，上述流程全部可用。
11. 在主页点击“选择资料库位置”并选择非 C 盘目录后，当前位置显示所选目录下的 `StudySeqData\materials`，重启 App 后仍保持该位置。
12. 迁移到自选位置后新导入资料落在该 `StudySeqData\materials` 下，PDF / 图片 / 视频预览仍可用。
13. 在主页点击“迁回默认位置”后资料能继续打开，当前位置回到默认 AppData 资料库。

### UI 验收

1. 主页仍是单栏学习内容列表。
2. 不出现日历、时间线、右侧信息面板或独立足迹列表。
3. 每个学习主题栏只显示上次打开时间、上次打开文件、上次打开位置三类最近打开信息。
4. 长文件名能截断或换行处理，不挤压进度条、编辑按钮和删除按钮。
5. 无记录状态清晰，但不喧宾夺主。
6. 键盘焦点、按钮可达性和文本对比度不低于现有主页水平。

## 风险

### 视频进度保存频率

影响：如果每秒写库，可能造成不必要的 IO 压力。

建议：使用低频保存策略，例如暂停、跳转、离开页面、固定间隔或播放位置变化达到阈值时保存。

### 最近打开摘要与资料删除的一致性

影响：删除资料后，主页可能引用已不存在的资料。

建议：删除资料和删除学习内容路径必须覆盖最近打开摘要清理；主页查询时也应对失效引用做兜底。

### PDF 状态重复

影响：如果为 V1.4 新建一套 PDF 页码状态，可能与现有 PDF 阅读状态冲突。

建议：优先复用现有 `material_reading_states` 能力，只扩展主页摘要输出。

### 普通文件位置不可定位

影响：普通文件没有页码或播放时间，硬造“位置”会误导用户。

建议：普通文件只显示上次打开时间和文件名；位置字段为空时不展示。

### 主页信息密度

影响：学习主题栏可能被三项最近打开信息撑得过高。

建议：保持三项信息短句展示；文件名做截断；不要加入学习时长、连续天数、热度等额外信息。
